# ATM Interface

## Description

A Java-based ATM Interface application developed using Object-Oriented Programming concepts.

## Features

* Create Account
* PIN Authentication
* Account Details
* Balance Inquiry
* Deposit Funds
* Withdraw Funds
* Transaction History
* Withdrawal Limit Validation

## Technologies Used

* Java 17
* VS Code

## How to Run

Compile:

javac *.java

Run:

java Main

## Concepts Used

* Classes and Objects
* Constructors
* ArrayList
* Encapsulation
* User Input Handling
* Conditional Statements
* Loops
